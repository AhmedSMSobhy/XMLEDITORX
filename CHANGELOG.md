# Changelog

## 1.0.0, 2026-09-04

First public release.

- Large-file XML editing: tree, source editor with minimap and magnifier, subtags, inspector, preview, errors with fixes.
- Charts (quick chart and chart builder), Orbit view, element-aware Diff with block or line copies and undo.
- Find and Replace with CSV export, six themes, per-pane and application zoom.
- Marker pen in four colours: drag over the words to paint them, marks remembered per file, jump from mark to mark.
- Learn pane with an AI chat beside the file: send the selection or the element, show the file in File Explorer, copy the whole file.
- Drag the selected text or a tree element into the chat page, into the file itself, or into any other program.
- The minimap can be hidden from the small button above it.
- Tabs, untitled documents, files opened by drag and drop, settings window, guided tour.
